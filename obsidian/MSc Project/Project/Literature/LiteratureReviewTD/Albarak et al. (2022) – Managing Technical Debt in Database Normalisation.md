## Summary
Proposes a multi-attribute analysis framework using Portfolio Theory and TOPSIS to rank database tables for normalisation based on estimated impact on data quality, performance, maintainability, and cost. Evaluated through an industrial case study of a HR management web application.

## Key Arguments
- TOPSIS provides a principled, multi-attribute ranking mechanism for TD items that outperforms heuristic approaches
- Debt-aware normalisation ranking reduces effort and cost while prioritising highest-impact items
- Portfolio Theory provides a complementary lens for balancing TD remediation investment
- Multi-attribute analysis is feasible and practically valuable in a real industrial TD context

## Key Concepts
- TOPSIS for TD prioritisation
- Multi-attribute analysis
- Portfolio Theory
- Database normalisation debt

## Relevance to Project
Direct methodological precedent for applying TOPSIS to TD prioritisation. Cited in section 2.8.2 (TOPSIS: Mechanics, Applications, and Critical Limitations). My framework extends this precedent from database-level schema debt to service-level operational TD.
