## Summary
Proposes a modified TOPSIS formulation that eliminates the rank reversal problem, a well-known instability where adding or removing an alternative changes the relative ranking of existing alternatives. Validated mathematically and through numerical examples.

## Key Arguments
- Rank reversal is an inherent vulnerability in standard TOPSIS that undermines its credibility for dynamic decision problems
- The proposed modification produces stable rankings regardless of the alternative set composition
- The fix is mathematically elegant and does not significantly increase computational complexity
- Rank stability is especially important in contexts where the alternative set changes over time

## Key Concepts
- Rank reversal problem
- TOPSIS stability
- MCDM robustness
- Dynamic alternative sets

## Relevance to Project
Section 2.8.2 (TOPSIS: Mechanics, Applications, and Critical Limitations). Essential for methodological credibility, service portfolio changes over time as services are added, retired, or restructured, making rank stability a non-trivial concern.
